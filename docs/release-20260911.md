## 安装
下载 [ZIP](../downloads/image-search-v7-20260911.zip?raw=true) 并解压。在 Chrome 地址栏输入 chrome://extensions，开启开发者模式，点击“加载已解压的扩展程序”，选择内含 manifest.json 的文件夹。若已安装旧版，停用旧版后加载新版，避免两版混用。插件设置中选择网站；Capture 用于框选截图，Browse 用于选择本地图片。
